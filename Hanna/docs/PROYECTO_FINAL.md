# Proyecto final profesional Hanna

Hanna queda preparada como asistente modular con backend robusto, perfiles de arranque, diagnóstico seguro, sanitización y scripts de revisión. El proyecto no se considera cerrado: la UI visual y futuras integraciones quedan en roadmap.

## Implementado

- Perfiles `full`, `hybrid`, `telegram_only`.
- Diagnóstico operativo por comandos.
- Logs seguros por canal.
- Sanitización defensiva de secretos.
- Scripts de prueba final.

## Preparado, no implementado

- Revisión avanzada de ZIP/proyectos con confirmación interactiva.
- UI/panel visual renovado.
- WhatsApp.

## Comandos preparados, no implementados

- `/revisar_archivo`
- `/revisar_zip`
- `/revisar_proyecto`
- `/revisar_conversacion`
- `/memoria deduplicar`
- `/memoria limpiar_interna`

Estos comandos responden de forma segura indicando el requisito pendiente; no prometen ejecución real.
