# Configuración de entorno

Crear `HannaEnv.env` localmente. No versionarlo.

Variables principales:

- `HANNA_MODE=full|hybrid|telegram_only`
- `TELEGRAM_TOKEN=`
- `TELEGRAM_ALLOWED_CHAT_IDS=`
- `GROQ_API_KEY=` para voz/transcripción y Groq.
- `GEMINI_API_KEY=` opcional.
- `OPENROUTER_API_KEY=` opcional.
- `OLLAMA_AUTO_START=true|false`
- `HANNA_ADMIN_WEB_ENABLED=true|false`
- `HANNA_WEBCHAT_ENABLED=true|false`
- `HANNA_MOBILE_API_ENABLED=true|false`
- `HANNA_LOCAL_HOTKEY_ENABLED=true|false`

Nunca subas secretos reales.
